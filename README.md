## ABOUT THIS PROJECT

**CURVE MINI** est une expérimentation ANKS Labs plus légère autour des courbes et du contrôle de paramètres. Le travail a permis d'explorer les limites d'un plugin VST3 qui voudrait piloter directement des macros externes sans mécanisme d'hébergement ni intégration spécifique au DAW.

> **Statut : expérimentation / piste non retenue comme solution VST3 autonome directe.** Ne pas interpréter ce dépôt comme un produit finalisé ou comme un outil prêt à piloter automatiquement les macros de tous les instruments.

Le retour d'expérience nourrit d'autres approches : **Curve Pilot** pour l'hébergement d'instruments, et une piste **Max for Live** pour le dialogue plus étroit avec Ableton Live.
